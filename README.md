# Incident RCA Analyzer

A simple Python-based project that simulates an incident analysis and Root Cause Analysis (RCA) workflow.

## Features

- Incident ID capture
- Application name
- Error message analysis
- HTTP status code analysis
- API response-time analysis
- Business impact recording
- Resolution tracking
- Basic RCA recommendations

## Technologies

- Python
- HTTP Status Codes
- Exception Handling
- Incident Management
- Root Cause Analysis (RCA)

## Example

Input:

Incident ID: INC-2026-001
Application: HRMS Payroll
HTTP Status: 504
Response Time: 8.7 seconds

Output:

Incident Type: Server / Backend Error

Recommended RCA:
Check application logs, database and backend services.
